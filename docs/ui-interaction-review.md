# 顾问交互重构与验证

本分支在 `v0.2.1` 审查修复基础上，重构设置页、咨询确认区、会话顶部工作台和结果操作。尚未发布新版本。

## 用户可见变化

| 场景 | 新行为 |
| --- | --- |
| 修改配置 | 按模型、使用方式、材料、交付分组；明确保存/放弃，显示未保存状态。连接检查只使用已保存配置；开关与会话授权即时生效。 |
| 离开正在编辑的界面 | 设置、咨询问题和核验表单的草稿保留在当前页面运行时，切换设置/会话或关闭面板不会静默丢失。刷新页面不持久化这些草稿；设置有离页提醒。 |
| 发起咨询 | 先填写问题、选择重点和本次材料范围，再预览实际正文与目标模型，最后确认调用。预览不调用模型；缺失/截断/旧轮次材料明确标识。 |
| 防止误发 | 编辑后需重新预览。发送携带材料摘要与目标模型；准备后发生变化会被服务端拒绝；快速重复点击受同步锁保护。 |
| 查看历史 | 顶部入口始终可发现；历史支持搜索与全部/待核验/进行中/未完成筛选。选中的旧记录在刷新时保持选中。 |
| 核验意见 | 卡片内独立填写结论、处理状态与依据，不读取或改写主对话草稿。非待定结论需提供依据。人工标注用中性措辞，不声称主力已经确认。 |
| 交付与取消 | 已交付按钮不再重复提交；失败明确显示。取消后保留真实终态；无意见、失败、拒绝和正常返回不混淆。 |
| 键盘与窄屏 | 原生表单控件、焦点样式、Escape 关闭并返回入口、表单展开后滚到可见位置。375 px 窗口和深色主题无页面横向溢出。 |

“跟随当前模型”使用宿主 `agentDefaultModel.currentSelection()`，没有把它宣传成宿主未提供的逐会话独立模型选择。自动模式对所有会话生效；当前会话临时授权是另一项操作，最长 24 小时。

## 重现

在源码 checkout 中执行。UI 测试依赖隔离在 `scripts/ui`，不进入插件运行时依赖：

```sh
node --test tests/*.test.mjs
npm ci --prefix scripts/ui
cd scripts/ui
npx playwright install chromium
cd ../..
npm run test:ui
```

若 CI 已有浏览器，可用 `DSH_UI_CHROMIUM=/absolute/path/to/chromium npm run test:ui`。依赖可选从 `DSH_UI_NODE_MODULES` 指定的已安装目录读取。本次环境常规浏览器下载失败，实际运行使用 `@sparticuz/chromium@138.0.2` 提供的 Chromium 可执行文件；此替代包不属于项目依赖。

本地人工预览：`node scripts/ui/server.mjs --serve`，打开输出的 loopback 地址；`?view=settings` 打开设置，`?theme=dark` 切换深色，`?lang=en` 切换英文。预览明确标注模拟环境，仅使用临时目录；退出后删除测试数据。测试会重建上述截图。

## 真实宿主仍需验证

当前环境没有 DSH 桌面宿主。合并前须检查真实槽位的高度、祖先容器变换/裁剪、主题 token、窗口缩放与 Tab 顺序；真实供应商目录、确认对话框和向主力交付的行为也需在干净 profile 中验证。现有模型工具与手动咨询仍采用两条详细历史路径，没有宣称已统一完整账本。

自动化测试不证明真实供应商停止生成、真实费用准确，或多窗口/多进程配置同步。本次保留原有安装接口与版本号，客户端与之前的 RPC 修复需要一起更新。
