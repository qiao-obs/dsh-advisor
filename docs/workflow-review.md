# 从顾问意见到日常工作闭环

本分支在已有设置/咨询界面和审查修复上，增加持久化待办、主力执行回报和人工验收。版本号仍为 0.2.1；这些改动尚未发布到该标签。旧版桌面验收结论不能直接用于本次新增能力。

## 可以实际怎么用

| 日常场景 | 操作与结果 |
| --- | --- |
| 讨论完方案就开始推进 | 用「执行方案」模板咨询，选择候选行动，编辑任务范围与验收条件，再预览并交给当前会话主力。 |
| 修复问题并复查 | 从具体意见建立待办；主力回报真实改动、检查结果和未验证部分。带着报告进行一次显式顾问复查，再人工验收。 |
| 继续昨天的工作 | 打开会话顶部待办，按待验收、阻塞、优先级查看；任务和依据随当前 profile 保存，关闭面板不丢已保存内容。 |
| 交接与复盘 | 导出 Markdown，包含原意见、模型执行报告和分开的人工判断。清空咨询历史不会清空工作证据。 |

手动咨询最多提取 3 个结构化候选行动，和意见使用同一次模型调用及现有输出预算。无合法完整结构或输出截断时不提取；仍保留原文，允许人工编辑为任务。候选行动不是自动执行指令。直接调用 `advisor_consult` 的完整历史仍采用旧工具路径，本次没有把两条咨询历史路径宣传为已经统一。

## 状态与交互

正常路径：待交付 → 交付确认中 → 已交付 → 待验收 → 人工确认通过。

- 每个任务必须有标题、执行范围、验收条件和优先级；交付前可修改，交付后需重新开放才能改范围。
- 主力可以报告完成、阻塞或不适用。完成/不适用都进入待验收，不能直接得到「人工确认通过」。主力报告与人工验收分别展示和保存。
- 交付超时或异常表示「交付状态不确定」，不是确定未送达。禁止自动重试；重新开放前需确认已经检查主对话、避免重复执行。
- 人工验收、暂缓、不采纳和重新开放都需要依据。过期表单不能覆盖期间新增的报告。
- 复查准备时绑定任务版本；材料异步采集期间如果任务变化，拒绝发起模型请求，要求重新预览。复查结论不自动关闭待办。
- 模型回报工具不可用时，任务说明要求主力在对话中报告相同字段；用户可依据实际证据手动验收。插件没有把报告存在视为检查真正通过。

桌面与 375 px 深色窄屏均有覆盖。主对话草稿不被任务或验收表单改写。面板关闭且无等待回报的任务时不轮询；面板打开约 5 秒刷新，等待执行回报时约 10 秒，咨询运行时约 1 秒；隐藏页面不触发周期刷新。

## 真实集成与存储边界

- 交付通过现有宿主 `agents.get(sessionId).followup`，不可用时回退 `inject`。后者只入队，不保证立即执行；接收确认不代表任务完成。
- 有真实 profile 数据目录时注册 `advisor_work_report`，无数据目录不注册。模型提交本次任务/派单 ID，实际会话由 `exec.agent.session.id` 决定，无法指定另一个会话写报告。人工决定会使旧派单 ID 失效。
- 待办独立存储在 `<DSH_HOME>/dsh-advisor/work/<SHA-256(sessionId)>.json`，避免会话 ID 进入文件路径。保留原意见快照、报告、验收记录和事件。单会话最多 500 项，每项保留最近 20 份报告/人工决定/复查关联和 80 条事件。
- 写入前重读、校验版本，再临时文件重命名；文件损坏时拒绝覆盖。适用于一个 profile 的单宿主写入，不支持多个进程同时编辑同一文件。
- 创建请求和同一来源的相同行动去重；派单在调用宿主前先写入状态，双击不能产生两次派单。超时后晚到的确认可修正交付状态，但不能覆盖执行回报或人工决定。卸载结束等待并保留不确定状态，晚到回调不继续写入。
- 新增工具只记录报告，不自己执行 shell、不绕过宿主权限、不自动调用顾问。主力正常执行成本不计入顾问调用上限；显式顾问复查计入已有手动咨询预算。没有跨项目调度、定时自动推进、外部任务系统同步或无限循环复查。
- 测试材料采集支持最新失败输出或常见 Node TAP、Jest、pytest 测试摘要，保留旧轮次和截断提示；不把普通文件读取/搜索的成功输出当作测试结果。匹配到成功摘要也不等于整个任务已通过验收。

## 合并前的真实 DSH 验收

当前环境没有 DSH 桌面或真实模型账户。以下仍未实测，不能以本地测试替代：

1. 在独立 profile 安装分支，检查第二个工具被宿主注册、输出结构正常显示，模型实际可用到该工具。
2. 空闲和忙碌两种状态分别交付单个任务，确认 followup/inject 的接收行为、任务原文、唯一派单 ID 与主对话草稿。
3. 完成一个小任务，验证模型写回真实检查证据、界面停在待验收，再带材料复查并人工验收。
4. 断开/重载时观察交付不确定提示，确认无自动重复发送，已保存任务重启后恢复，其他会话不能写入该任务。
5. 验证真实主题、窗口缩放、键盘焦点、宿主祖先容器裁剪和主力执行的权限提示；顾问调用预算与主力费用应分开理解。
